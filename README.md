## 🏫 ¿Qué es TeamFix?

**TeamFix Classroom** es una plataforma educativa de última generación diseñada para ofrecer una experiencia intuitiva, limpia y estructurada, inspirada en las mejores funciones de *Google Classroom*. Optimiza los flujos de aprendizaje permitiendo un acceso rápido a clases, administración de tareas asignadas y un seguimiento claro tanto para alumnos como para profesores.

<br />

    <td width="50%">
