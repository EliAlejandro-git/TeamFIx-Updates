## 🏫 ¿Qué es TeamFix?
**TeamFix Classroom** es una plataforma educativa diseñada para ofrecer una experiencia intuitiva, limpia y organizada, muy parecida a Google Classroom. Permite un acceso rápido a clases, gestión de tareas organizadas y un seguimiento claro tanto para alumnos como para maestros.

### ✨ Características principales:
* 🔑 **Acceso simplificado:** Ingreso rápido mediante código personal (ej. Alumnos, Profesores o Dirección).
* 📋 **Gestión de clases:** Visualización del trabajo en clase, anuncios y lista de personas.
* ⏳ **Control de entregas:** Panel dinámico para ver las próximas tareas pendientes y su puntaje.
* 💬 **Stream de novedades:** Recordatorios y avisos importantes en tiempo real para el grupo.
* 🌙 **Interfaz moderna:** Diseño optimizado con soporte para Modo Oscuro.
